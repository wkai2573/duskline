# 《晨昏戰線》完整規則

> 這份文件和 `src/engine/` 的實作一致。遊戲中按右上角「規則」可以看精簡版。

## 一、目標

雙方各有 3 座塔（左路、中路、右路），每座 **8 生命**。

- **摧毀對手 2 座塔**就立即獲勝。
- 打滿 **8 回合**還沒分出勝負時，塔的總生命較高的一方獲勝。
- 雙方在同一回合都失去第 2 座塔時，也比塔的總生命。總生命相同就是平手。

## 二、牌組

| 項目 | 規則 |
|---|---|
| 張數 | 剛好 20 張 |
| 同名卡 | 最多 2 張 |
| 衍生物 | 只能被召喚，不能放進牌組 |

目前有三副預設牌組（晨曦騎士團、暮影盟約、星軌學會），陣營裡的 10 種卡各放 2 張。

## 三、開局

1. 雙方洗牌，各抽 4 張起手。
2. 擲硬幣決定**第 1 回合由誰先揭曉**（主動權）。
3. 再擲一次硬幣決定**第 1 回合是白晝還是黑夜**。

> 第 1 回合的晝夜用擲硬幣決定，是因為最後一回合的晝夜影響很大。
> 固定從白晝開始的話，第 8 回合永遠是黑夜，模擬顯示暮影盟約的勝率會因此高出約 10 個百分點。

## 四、回合流程

### 1. 開始

- 回合數 +1。第 2 回合起，主動權交給另一方。
- 決定晝夜：一般情況下和上回合相反；如果上回合有人打出「永夜」，就維持黑夜。
- 雙方各抽 1 張牌。手牌上限 8 張，抽到超過的那張直接進棄牌堆。

### 2. 佈署（雙方同時進行）

- 第 N 回合有 **N 點魔力**，用不完的不會保留。
- 單位要指定放在哪一路，每路每方最多 **3 個單位**（包含這回合要放下去的）。
- 法術分兩種：**指定一路**的要選一路，**全場**的不用。
- **焚卷**：每回合可以把一張手牌移出遊戲（不會進棄牌堆），換這回合 +1 魔力。

雙方看不到對方這回合出了什麼。

### 3. 揭曉

1. 有主動權的一方先揭曉：先讓**預約的牌發動、流放的單位回來**，再處理焚卷，然後**依出牌順序**一張一張翻開。
2. 接著另一方用同樣的方式揭曉。

每張牌翻開時：

- 單位放到指定那一路的**最後方**，然後發動它的「揭曉：」效果。
- 法術發動效果後進棄牌堆。
- 如果那一路已經被同一回合的召喚佔滿，單位無法進場，直接進棄牌堆。
- **預約**的牌這回合只付費，翻開時放到一旁，下回合自己的揭曉階段開始時才進場或發動。

每張牌結算完，立刻移除生命歸零的單位。

> **後揭曉的比較有利嗎？** 後揭曉的一方可以用揭曉效果打到對手剛放下的單位，
> 晝夜法術也會蓋掉先揭曉的那一方。不過主動權每回合交換，所以雙方機會相同。

### 4. 交戰

三路各自結算，雙方**同時**出手：

1. 先記下每一路雙方的攻擊快照：
   - **一般攻擊** = 這一路所有非突襲單位在**目前晝夜**下的攻擊力總和
   - **突襲攻擊** = 這一路所有突襲單位的攻擊力總和
2. 一般攻擊從對方**最前方**的單位開始打。每個單位吃掉等同自己剩餘生命的傷害，多出來的繼續打下一個，最後溢出的部分打塔。
3. 突襲攻擊直接打塔。
4. 打塔的傷害（溢出＋突襲）先扣掉對方這一路所有單位的**守護值總和**，才真正打到塔。
5. 塔已經被摧毀的話，打到那一路的傷害就浪費掉。

因為用的是快照，同一次交戰中被打死的單位仍然會出手，守護也仍然有效。

交戰後：

- 有**吸血**的單位如果還活著，回復等同自己目前攻擊力的生命（不超過上限）。
- 移除生命歸零的單位並發動亡語。

### 5. 結束

判定勝負。還沒分出勝負的話，進入下一回合。

## 五、單位與傷害

- 單位的**生命值不隨晝夜改變**，受到的傷害會一直保留，直到被治療或陣亡。
- 單位陣亡後進持有者的棄牌堆；衍生物則直接消失。
- 已經被摧毀的塔**不能修復**。

## 六、關鍵字

| 關鍵字 | 效果 |
|---|---|
| 守護 N | 此路我方塔受到的傷害 −N |
| 突襲 | 攻擊不打單位，直接打塔 |
| 吸血 | 交戰結束時若仍存活，回復等同目前攻擊力的生命 |
| 揭曉 | 這張牌翻開時發動 |
| 亡語 | 這個單位陣亡時發動 |
| （白晝）／（黑夜） | 只在那個晝夜發動，以**發動當下**的晝夜為準 |
| （先揭曉）／（後揭曉） | 只在自己這回合先揭曉／後揭曉時發動 |
| 預約 | 這回合付費，下回合自己的揭曉階段開始時才進場（單位）或發動（法術）。單位進場時才檢查戰線是否已滿，滿了就進棄牌堆。對手看不到預約的是什麼牌。最後一回合不能預約，因為不會生效 |
| 流放 | 把敵方最前方的單位移出戰場，它下回合（敵方的揭曉階段開始時）帶著原本的生命回到同一路的最後方。流放期間它不會出手，也不會擋傷害；回來時不會再發動揭曉效果。回來時那一路已滿，單位進棄牌堆（衍生物直接消失） |

亡語可能再打死其他單位，引擎會重複結算直到沒有新的陣亡。

## 八、平衡紀錄

數值基準：看卡面上最強的那一面，「最高攻擊力＋生命」大約是 1 費 3～4、2 費 5～6、3 費 4～6（有能力的偏低）、4 費 9、5 費 12。
晨曦和暮影有天色法術可以強迫天色，單位大多能以強的那一面出手；星軌的單位攻擊力不隨晝夜改變，用同一個基準比較。
預約的單位比同數值的單位便宜 1 費（晚一回合才進場）。同費用的單位，這個數值相差不超過 3（有測試檢查）。
所有調整都用 `npm run sim` 讓兩個 AI 大量對打來驗證。

| 版本 | 調整 | 晨曦勝率 |
|---|---|---|
| 初版 | — | 31% |
| 1 | 狼人村民 ☾4→3、月下狼王 ☾7→6 | 34% |
| 2 | 第 1 回合晝夜改為擲硬幣（原本固定白晝） | 42% |
| 3 | 盾衛生命 4→5、聖光修女修復 3→4 | 46% |
| 4 | 聖光審判費用 3→2 | **48.7%**（2000 局） |

目前的模擬結果（2000 局）：平均 7.5 回合，一半的對局在第 8 回合前就摧毀兩座塔，
首回合主動權和座位都沒有明顯偏差（勝率各約 50%）。

### 星軌學會（第三陣營）

第一版（單位攻擊力偏低、1 費的星圖預演、3 費的 5/5/5 預約巨像）在 AI 對打時只有 11%～14% 勝率，
把單位的攻擊力調高到 50% 左右後，玩家實際玩起來卻覺得部分單卡太強、同費用的數值差太多。
AI 不太會用預約和流放，用勝率調出來的數值不能直接相信，所以第二版改成先訂**卡面數值的規則**（見上面的數值基準，
有 `tests/cards.test.ts` 檢查），再用模擬確認勝率沒有差太多：

| 調整 | 原因 |
|---|---|
| 星軌巨像 5/5/5（3 費）→ 3/3/4（2 費） | 3 費的 5/5/5 比同費用的單位強太多；預約改成「便宜 1 費」來補償晚一回合 |
| 時隙伏兵 2/2/3 維持 1 費 | 預約的單位比同數值便宜 1 費 |
| 鐘樓守衛 3/3/4 → 3/3/3 | 2 費的單位最高攻擊力＋生命不超過 6 |
| 星圖預演 1 費 → 2 費 | 1 費就能打每一路的最前排太划算 |
| 星軌執政官 5/5/6 維持 | 5 費單位 12 左右，有後揭曉能力所以略低 |

用 `npm run sim` 讓三個陣營兩兩對打（各 2000 局）：

| 對戰 | 星軌勝率 |
|---|---|
| 對晨曦騎士團 | 48.0% |
| 對暮影盟約 | 47.3% |

這是 AI 對打的結果，AI 比人類更不會利用預約、流放和揭曉順序，所以真人玩家對上 AI 時星軌的實際勝率會更高。
`npm run card-power -- orbit` 可以逐張牌分析：把某一種卡換成同費用的白板單位，看勝率變化。
